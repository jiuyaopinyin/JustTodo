# JustTodo

A tiny, native macOS to-do list that lives on the edge of your screen. No account, no cloud sync, no extra clutter. Supports English and Chinese.

一个原生 macOS 轻量待办工具。每个项目是显示“已完成数/总数”的独立贴边标签，例如 `0/5`、`3/5`，空项目显示 `0/0`。侧边为 60 × 50 点，顶部自动交换为 50 × 60 点。靠边的一端平直，朝内的一端呈圆弧。背景默认 80% 透明，可独立调整；数字保持清晰。使用 SwiftUI + AppKit，无第三方依赖，支持 macOS 14 及以上。

## 下载与安装

从 [GitHub Releases](https://github.com/jiuyaopinyin/JustTodo/releases/latest) 下载适合你的 Mac 的安装包，打开 DMG 后将 JustTodo 拖入 Applications。

| Mac 类型 | 安装包 |
| --- | --- |
| Apple 芯片（M 系列） | `JustTodo-1.0.0-arm64.dmg` |
| Intel 芯片 | `JustTodo-1.0.0-x86_64.dmg` |

两个版本均要求 macOS 14 或以上，内含应用经 Developer ID 签名并通过 Apple 公证。数据仅保存在本机。公证票据随应用附带，DMG 本身另行签名。

## 运行

```sh
swift run
```

打包为可双击的应用：

```sh
zsh scripts/build-app.sh
open dist/JustTodo.app
```

可以把 `dist/JustTodo.app` 拖到“应用程序”。本地构建使用临时签名；对外分发需开发者签名和公证。更名沿用原应用标识和 `EdgeTodo` 数据目录，已有项目与设置可直接继续使用。

### Apple 芯片与 Intel DMG

打包脚本默认生成 `arm64` 架构，设置 `ARCH=x86_64` 可构建 Intel 版本，最低系统为 macOS 14。制作包含应用和“Applications”快捷方式的 DMG：

```sh
zsh scripts/build-app.sh
zsh scripts/build-dmg.sh
```

默认输出为 `dist/JustTodo-1.0.0-arm64.dmg`；脚本不会覆盖同名 DMG，并自动根据应用架构命名。第二个脚本也支持传入应用路径和输出路径。

Intel 构建可使用独立目录：

```sh
ARCH=x86_64 APP_OUTPUT_PATH="$PWD/dist/intel/JustTodo.app" zsh scripts/build-app.sh
zsh scripts/build-dmg.sh dist/intel/JustTodo.app
```

正式发布时，通过 `SIGNING_IDENTITY` 环境变量指定本机的 `Developer ID Application` 证书；应用签名会启用 Hardened Runtime 和 Apple 安全时间戳。`APP_OUTPUT_PATH` 可将发布构建放到独立目录。先向 Apple 提交应用公证并导出带票据的应用，再运行：

```sh
SIGNING_IDENTITY='Developer ID Application: YOUR NAME (TEAM_ID)' \
  zsh scripts/build-dmg.sh dist/notarized/JustTodo.app
```

DMG 脚本保留应用内的公证票据，并签名磁盘映像。仅完成构建或签名不代表通过 Apple 公证；发布前需使用 `xcrun stapler validate` 和 `spctl --assess --type execute` 验证应用。

## 操作

- 默认跟随系统语言，支持中文和英文，其他系统语言回退到英文。菜单栏或详情“更多”中的“语言 / Language”可选择“跟随系统 / 中文 / English”，立即生效并保存。
- 外侧标签数字使用内置的 Orbitron SemiBold 几何科技风字体（[来源](https://github.com/googlefonts/orbitron-vf)，SIL Open Font License，许可证随字体打包）；详情界面继续使用 macOS 等宽字体 SF Mono，中文使用系统 CJK 后备字体。已有项目名称与待办正文不翻译、不改写；日期、提示、按钮与菜单随界面语言切换。
- 点击项目卡片，展开或收起详情；数字会随任务状态更新。
- 标签接受窗口失焦后的第一次点击；小于 5 点的鼠标移动仍视为单击，超过阈值才开始拖动。右键弹层关闭不会消耗下一次标签点击。
- 拖动任意卡片到内置或外接显示器，松手后吸附到鼠标所在屏幕最近的左侧、右侧或顶部；各项目独立保存显示器、方向与位置，详情在同一屏幕内展开。
- 右键标签打开紧凑设置浮窗：上排七种颜色，中间是透明度滑杆和百分比，下方直接显示待办输入框及“添加”按钮。回车或点击“添加”即可加入该标签对应的项目；成功后清空输入框，浮窗保持打开，方便连续添加。空白内容不可提交，不再使用加号和二次弹窗。颜色与透明度分别保存到每个项目。
- 透明度向右增加，范围为 0%–100%，调整时实时生效；数字不受背景透明度影响。鼠标悬停显示项目名称。
- 左右贴边时向屏幕内侧露出半圆端；顶部贴边时下方圆角朝内，数字位于下部。
- 点击任务左侧圆圈完成任务，再次点击恢复。任务文字支持选中复制，点击或拖选文字不会改变完成状态。完成任务显示删除线。
- 每次勾选完成一条任务，彩纸从该任务完成按钮的位置向外喷射并自然散落，约 2 秒后消失；取消完成不触发。动画不阻挡点击或输入，切换项目或重新打开详情后清除；系统启用“减少动态效果”时改用按钮附近的静态彩纸淡出。
- 每条任务正文默认最多显示 5 行（包含自动换行）。超出时右下角显示“展开 / 收起”；短任务不显示按钮。展开后可选中完整正文复制。
- 项目标题、任务文字、日期、进度数字和透明度文字可选中后按 Command-C 复制；任务保留系统默认右键行为。浮动数字标签获得键盘焦点时可用 Command-C 复制数量。
- 详情为直角卡片，20 点标题位于左上角，“更多”省略号图标位于右上角；圆环进度位于标题左侧，环内显示“已完成数/总数”（如 `3/7`），背景使用当前项目颜色的浅色版本。
- 列表右上角的筛选按钮显示当前筛选，点击直接显示“未完成 / 已完成 / 全部”三个选项，当前选项带勾，无二级菜单。每次打开详情默认显示未完成（To do）；任务均严格按创建日期和时间倒序。“全部”混合显示所有状态的任务，完成任务仍保留删除线。
- 底部只保留输入框，输入任务后按回车添加；Command-N 聚焦输入框。
- 今天的任务直接显示；其他日期的任务按天分组并显示日期区头，日期与任务均按时间倒序。每条任务的右上角显示时间。
- 在任务上用触控板向左滑动，从右侧露出“编辑”和“删除”按钮，向右滑动收起；任务的编辑和删除仅通过滑出按钮操作，不接管任务的系统右键菜单。多行编辑框支持换行，点击保存或 Command-Return 提交，取消或 Esc 放弃修改；原创建时间和完成状态保持不变。详情右上角菜单可重命名、删除项目。
- 吸附方向通过拖动切换，右键设置弹层不包含方向菜单。也可使用详情菜单管理项目。
- 菜单栏图标提供显示／隐藏、新建项目和退出；吸附位置通过拖动标签调整。
- 点击应用外部或按 Esc 收起详情，项目卡片仍然驻留。
- 浮窗按各自显示器的可用区域定位，支持左右、上下排列和不同缩放比例。断开外接屏时临时移到主屏，重新连接后恢复已保存的显示器位置；在回退屏幕上主动拖动会保存新位置。旧数据默认放在主屏。支持多个桌面；全屏应用中的显示受 macOS 空间管理影响。

任务保存在 `~/Library/Application Support/EdgeTodo/tasks.json`，每次操作自动原子写入。关闭再打开后恢复项目、任务、位置、颜色、透明度与语言设置。旧数据默认沿用 80% 透明度和系统语言。如果原数据损坏，会保留原文件并显示错误，避免覆盖。

应用首次运行且没有本地数据时创建三个项目，名称根据初始语言使用“收集箱、工作、生活”或“Inbox、Work、Personal”。每个项目包含一条同语言的未完成示例待办，第一个项目额外包含“左滑可编辑或删除待办”的示例，因此外侧分别显示 `0/2`、`0/1`、`0/1`。首次启动自动打开第一个项目，并让新增示例直接露出右侧“编辑 / 删除”按钮，不进入编辑窗口；该引导只展示一次。示例可以编辑、完成或删除。已有数据（包括主动清空的项目和任务）不会补入示例。无联网、账号和云同步。

```sh
swift test
```
